# SC34–SC37

## SC34 (Rev.1 Nov 2005) Automatic sprinkler, fire detection and fire alarm system

**(FSS Code, Ch. 8, 2.5.2.3)**

Nominal area is defined as being the gross, horizontal projection of the area to be covered.
*(MSC/Circ. 1120)*

## SC35 (Rev.1 Nov 2005) Fixed fire detection and fire alarm system

**(FSS Code, Ch. 9, 2.2)**

The main (respective emergency) feeder shall run from the main (respective emergency) switchboard to the change-over switch without passing through any other distributing switchboard.
