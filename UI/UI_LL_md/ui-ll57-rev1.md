# LL57 Block Coefficient of a Multi-hull Craft (Regulation 3(7))

LL57
(1996)
(Rev.1 July 2008)

When calculating the block coefficient (C<sub>b</sub>) of a multi-hull craft according to the definition of Regulation 3(7), the full breadth (B) as defined in regulation 3(4) is to be used and not the breadth of a single hull.

Footnote: This UI is also applicable to Regulation 3(7) of the 1988 Protocol.
